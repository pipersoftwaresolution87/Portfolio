GeoTask: Location-Based TODO & Spatial Geofence Engine

github.com/fenil09/Location_TODO

Full-stack location-based reminder and TODO application powered by an asynchronous Python FastAPI backend, Firebase Firestore NoSQL persistence, and a custom Haversine Great-Circle Distance Engine for spatial geofence evaluation (20m to 2000m radius).

🛠️ Key Technical Deliverables:
  • FastAPI & Pydantic Schema Validation: Asynchronous REST API (`/api/todos`, `/api/todos/nearby`) enforcing strict type safety (`TodoCreate`, `TodoUpdate`, `TodoResponse`).
  • Geospatial Haversine Algorithm: `iswithin_radius()` computes exact user-to-task distances in meters based on `EARTH_RADIUS_METERS = 6371000.0`.
  • Leaflet.js Map & GPS Tracking: Continuous browser `watchPosition` GPS tracking, dynamic geofence radius visualizers, and location pin picking.
  • Proximity Audio & Toast Engine: Triggers automatic Web Audio API chime alerts when entering active task geofence radiuses.

Load Testing API: High-Concurrency Performance & Benchmarking Engine

Live Hosted App

High-scale distributed load testing platform designed to programmatically simulate Virtual User (VU) traffic against target servers to measure real-time Requests Per Second (RPS) and exact latency percentiles (p50, p90, p95, p99).

🚀 Business Applications & Use Cases:
  • Traffic Spikes Prep: Simulates high concurrency traffic hitting checkout and API routes to identify backend locks and memory bottlenecks.
  • Automated CI/CD Testing: Triggers automated load tests in deployment pipelines, automatically failing builds if p95 latency exceeds performance thresholds.
  • Performance Benchmarking: Generates latency and throughput verification reports to test high-concurrency compliance.
🛠️ Key Technical Architecture:
  • FastAPI & Async Core: Built with `Python FastAPI`, `httpx`, `asyncio`, and `uvloop` for high-performance non-blocking Virtual User simulation.
  • Task Queue & Telemetry: Redis + ARQ task queues for background load generation and WebSockets for real-time telemetry streaming.
  • Pydantic Boundaries (`ge`/`le`): Enforces schema guardrails (`virtual_users`: `ge=1, le=5000`, `duration_seconds`: `ge=1, le=3600`) returning HTTP 422 before execution.
